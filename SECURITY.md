# Security policy

## Reporting a vulnerability

Please do not open a public issue for a security problem.

Report it privately with GitHub private vulnerability reporting:
<https://github.com/SDK-E/agentsone/security/advisories/new>

Include what you found, how to reproduce it, and which version or commit you tested.
We will acknowledge your report, keep you updated while we work on a fix, and credit you
in the advisory if you wish.

## Supported versions

The project is a work in progress. Only the latest commit on `main` is supported until the
first release. After that, this page will list the supported release lines.

## Scope

This covers the code in this repository, including the daemon, the command line tools, the
interface, the runners, the plugins and the system image configuration. Problems in third-party
dependencies should be reported to their maintainers, but let us know if they affect this project.
