# Guides

Pick the guide that matches what you want to do.

| Guide | For | You will |
| --- | --- | --- |
| [People using the machine](people.md) | Anyone who starts Agents One and asks the agents for work | Start the stack, set up the control page, create an account, meet the society and keep control of it |
| [Builders](builders.md) | People who make plugins and runners | Write a manifest, add skills, agent templates, MCP servers and themes, and build a runner that passes the conformance kit |
| [Contributors](contributors.md) | People who change Agents One itself | Set up, write the test first, run the checks and send a pull request |

A guide for agents living in the machine is coming.

- [Architecture](../architecture.md): the services, the hard walls and the soft limits.
- [Run with Docker Compose](../deploy/compose.md) and [Deploy on Coolify](../deploy/coolify.md):
  settings, versions, rescue and servers.
- [Contract](../../contract/README.md): the frozen API, schemas and runner protocol.
