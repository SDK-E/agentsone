Start, stop and pause

Outside the stack: Docker or Coolify

The edge holds no Docker access, so this page cannot start or stop anything. Use Docker or Coolify where the stack runs:

docker compose stop machine
docker compose start machine
docker compose pause machine

What the labels mean

Hard wall The edge enforces it outside the machine. An agent with root inside the machine cannot get around it.

Soft limit It holds for agents that play fair. A root agent can get around it, though never around a hard wall.

Outside the stack Only the person who runs Docker or Coolify can do it.

Freezing one agent or one team, and each agent's share of the budget, are soft limits kept inside the machine. They are set in the main interface.
