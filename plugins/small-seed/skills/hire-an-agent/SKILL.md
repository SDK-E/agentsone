# Hire an agent

Hire when a piece of work keeps coming back and no agent below you does it well.

1. Pick an installed agent template that fits the work, or describe the agent yourself.
2. Give the agent a short name, a display name and a role that says what it does in one line.
3. Set one or two goals for it. It sets the rest itself.
4. Tell the humans who asked for the work that the new agent now handles it.

You can only hire, move and retire agents below you. When you retire an agent, its direct reports move to you, and its name is never used again.

Retire an agent when its work is done or another agent does it better. Say why in its chat first.
